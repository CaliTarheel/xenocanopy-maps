# Xenocanopy

**Live site:** <https://xenocanopy-maps.srider.chatgpt.site/>

**Public source:** <https://github.com/CaliTarheel/xenocanopy-maps>

Xenocanopy is an alien-jungle tactical battlemap generator for low-level revised
fifth-edition play. It creates procedural terrain, encounter prompts, player and
GM exports, and a setup brief for Roll20.

## Local development

Requires Node.js 22.13 or newer.

```bash
npm ci
npm run dev
```

Run `npm test` for a production build and rendered-page checks.
